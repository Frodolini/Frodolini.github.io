Kva skjer bak kulissene?

Sida er rein HTML og JavaScript på GitHub Pages. Ho snakkar direkte med ein Postgres-database hos Supabase. Nøkkelen i kjeldekoden er offentleg, så kven som helst kan finne han. Det er difor databasen som avgjer kva som er lov, med Row Level Security (RLS):

-- Alle kan lese
create policy "Alle kan lese meldingar" on meldingar
  for select using (true);

-- Innlegging berre når brytaren er på
create policy "Innlegging berre når tavla er open" on meldingar
  for insert with check (
    (select open from innstillingar where id = 1)
  );

Det finst ingen regel for update eller delete, så ingen kan endre eller slette meldingar frå nettsida. I tillegg har tabellen grenser på lengda (maks 30 teikn namn, 200 teikn tekst), og nettsida får berre lov å fylle ut namn og tekst. Tidspunktet set databasen sjølv.

Brytaren open i tabellen innstillingar kan berre læraren endre, i Supabase-dashbordet. Nye meldingar og endringar på brytaren kjem ut til alle med ein gong via Realtime (WebSocket).

Prøv sjølv: Opne utviklarverktøya (F12) og sjå på nettverksfana når du sender. Prøv å sende når tavla er stengd: då svarar databasen med feilkode 42501 (brot på RLS).
